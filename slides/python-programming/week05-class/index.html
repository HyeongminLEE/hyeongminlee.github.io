Recap · 3

Input validation

score = int(input("Score: "))

while score < 0 or score > 100:

print("A score is from 0 to 100.")

score = int(input("Score: "))

print(f"Your score: {score}")

←ask once, before the loop

←while the answer is not valid

←ask again, inside

Score: 150

A score is from 0 to 100.

Score: 85

Your score: 85

ask once before the loop · ask again inside it, until the answer is valid

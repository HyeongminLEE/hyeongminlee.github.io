Recap · 3

Quotes make a string.

with quotes, without quotes

>>> age = 20

>>> print("age")

age

>>> print(age)

20

two kinds of quotes

"Kim" · 'Kim'

the same string

"It's"

a quote inside: use the other kind outside

three kinds so far

>>> type(3)

<class 'int'>

>>> type(3.0)

<class 'float'>

>>> type("3")

<class 'str'>

with quotes: a string, shown as it is · without quotes: a variable, and Python uses its value · "3" and 3 look alike on the screen: type() tells you the kind

Recap · 5

input() always gives a string.

the user typed 20

age = input("Age: ")

print(age * 3)

202020

no error, and a wrong answer: the worst case

print(age + 1)

TypeError

can only concatenate str (not "int") to str

age = int(input("Age: "))

from the inside out: input() gives "20", int() turns it into 20, = stores it

changing the kind

  • int("20") → 20
  • int("3.5") → ValueError
  • int("twenty") → ValueError
  • float("3.5") → 3.5
  • int(3.9) → 3 cut, not rounded

digits typed by the user are still a string · "20" is not 20

Recap · 6

f-strings: an f before the quote, values in braces.

print(f"{name}, you are about {days} days old.")

Kim, you are about 7300 days old.

print(f"{days * 24} hours")

175200 hours anything inside the braces is calculated

print(f"{1 / 3:.2f}")

0.33 :.2f · two digits after the point, rounded

print("Hello, {name}")

Hello, {name} no f: no error, the braces are printed as they are

one string · no plus signs · no str()

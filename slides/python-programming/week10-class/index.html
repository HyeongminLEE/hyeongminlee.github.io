Exercise 8 · Problem 3

Two dice

week10_problem3.py 5 points

Roll two dice as many times as typed. Count how many times each sum from 2 to 12 comes, print the counts from 2 to 12, and draw them as a bar chart. Which sum comes most often?

on the screen · one run

steps, in words

  1. 1 Ask for the number of rolls. Start a dictionary with every sum from 2 to 12 as a key, each with 0.
  2. 2 That many times: roll two dice, add the two faces, and count that sum.
  3. 3 Print each sum with its count.
  4. 4 Draw the counts as a bar chart, and show it.

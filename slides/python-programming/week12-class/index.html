Exercise 10 · Problem 1

Power strip

week12_problem1.py 2 points

A power strip has three devices. Each keeps its name, its watts, and whether it is on (all start off). The class Device is started for you, and the program below it is given: write the body of each method.

in the file a dashed box is a body to write

class Device:

def __init__(self, name, watts):

keep name and watts; on starts as False

def switch(self):

turn on if off, and off if on

def power(self):

return watts if on, and 0 if off

tv = Device("TV", 120)

heater = Device("Heater", 2000)

lamp = Device("Lamp", 30)

devices = [tv, heater, lamp]

while True:

name = input("Switch: ")

if name == "":

break

for d in devices:

if d.name == name:

d.switch()

total = 0

for d in devices:

total += d.power()

print(f"Total: {total} W")

in the file a dashed box is a body to write

class ParkingLot:

def __init__(self, spaces):

keep spaces; the list cars starts empty

def park(self, car):

add car, print Parked: 1234; or Full.

def leave(self, car):

take car out, print Left: 1234; or No such car.

def show(self):

print 2 of 3 spaces used

lot = ParkingLot(3)

while True:

if command == "":

break

lot.park(input("Car: "))

lot.leave(input("Car: "))

lot.show()

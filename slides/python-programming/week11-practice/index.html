A week's temperatures

temps.py

temps.txt holds a day and its temperature on each line. Print the average temperature, to one decimal place, and the warmest day.

temps.txt

Mon,12.5

Tue,14.0

Wed,9.5

Thu,11.0

Fri,15.5

Sat,13.0

Sun,10.5

on the screen

week11 % python3 temps.py

Average: 12.3

Warmest: Fri

temps.py

temps = {}

with open("temps.txt") as f:

for line in f:

day, temp = line.strip().split(",")

temps[day] = float(temp)

average = sum(temps.values()) / len(temps)

print(f"Average: {average:.1f}")

top = max(temps.values())

for day, temp in temps.items():

if temp == top:

print(f"Warmest: {day}")
